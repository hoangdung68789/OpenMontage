Privacy Policy: ICYFOX Publisher

Last updated: 22 November 2026

ICYFOX Publisher ("the tool") uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the tool

Only the owner of the ICYFOX channel. The tool is not offered to anyone else.

What data the tool accesses

  • The owner's channel and video information, to upload videos and set their title, description, tags, thumbnail, captions and scheduled publish time.
  • The owner's channel analytics (views, watch time, traffic sources), to plan future videos.

How data is stored and shared

  • The OAuth refresh token is stored only on the owner's computer, in a local file that is never published.
  • Analytics reports are stored as files in the owner's private workspace for planning. Authorized data other than the owner's own reports is kept no longer than 30 days.
  • No data is sold or shared with third parties. No advertising or tracking is used.

How to revoke access

Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions. After revocation, the stored token is deleted and any stored data obtained through the API is deleted within 7 days.
