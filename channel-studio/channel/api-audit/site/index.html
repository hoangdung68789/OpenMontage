ICYFOX Publisher

ICYFOX Publisher is a private command-line tool used only by the owner of the ICYFOX channel on YouTube. It uses YouTube API Services to upload the owner's finished videos as Private, apply the title, description, tags, thumbnail and captions, schedule the publish time the owner chose, and read the channel's own analytics.

The tool is not offered to the public and no other user can sign in to it.
