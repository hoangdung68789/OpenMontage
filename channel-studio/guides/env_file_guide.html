Nhập khóa API vào file nào? (máy tính của anh)

Chỉ có MỘT file: .env nằm trong thư mục OpenMontage. Làm SAU khi Claude Code đã clone repo về máy. Ảnh minh họa, khóa dưới đây là ví dụ giả.
1Vị trí file cần tạo
C:\Users\Admin\HDRE AI\ClayLapis\OpenMontage\.env
  • Cùng thư mục với file AGENT_GUIDE.md và README.md của OpenMontage.
  • Tên file đúng là .env, không có chữ nào trước dấu chấm, không có đuôi .txt.
2Tạo file từ mẫu có sẵn
Chép:  ...\OpenMontage\channel-studio\config\api_keys.env.example
Dán vào: ...\OpenMontage\  →  đổi tên thành .env
  • File Explorer: bật View → Show → File name extensions trước, để không bị thành .env.txt.
  • Hoặc gõ trong PowerShell: cd "C:\Users\Admin\HDRE AI\ClayLapis\OpenMontage" rồi copy channel-studio\config\api_keys.env.example .env
3Mở .env bằng Notepad, điền khóa ngay sau dấu =, rồi lưu (Ctrl+S)
.env - Notepad
# (các dòng bắt đầu bằng # là ghi chú, giữ nguyên)

  • Đúng: GEMINI_API_KEY=AIzaSy... · Sai: GEMINI_API_KEY = AIzaSy... (có dấu cách) · GEMINI_API_KEY="AIzaSy..." (có dấu nháy)
  • Giá trị YouTube lấy từ Notepad anh đã lưu lúc làm OAuth Playground. Gemini, OpenAI, ElevenLabs lấy ở trang của từng dịch vụ.
4Kiểm tra: gõ cho Claude Code trên máy "kiểm tra API"
  • Dòng đầu phải ghi: 0. Nguồn khóa: file ...\OpenMontage\.env
  • Không dán khóa vào khung chat. File .env không bao giờ lên GitHub (đã chặn sẵn).
